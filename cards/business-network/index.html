A network can become more useful as it grows

A network effect occurs when participation changes value for other users.

The idea

A messaging service can become more useful when the people you need join it. More users do not improve every product automatically.

An example

A chat app used by all your friends is easier to use for communication than an isolated alternative.

Put it into practice

Identify who benefits from each additional participant.
