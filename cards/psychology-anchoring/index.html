The first number can set the frame

Anchoring occurs when an initial value influences a later judgement.

The idea

An early number can pull an estimate toward it even when it is a poor reference. Independent comparisons help.

An example

An expensive first offer makes a slightly cheaper second offer feel like a bargain, despite lower prices elsewhere.

Put it into practice

Form your own estimate before seeing someone else's.
