Good structure also needs true starting points

A sound deductive argument is valid and has true premises.

The idea

A tidy logical chain can still mislead if it begins with a false claim. Soundness requires both parts.

An example

A claim about every customer cannot be established using an unverified premise about all people.

Put it into practice

Ask: does it follow, and are its starting claims true?
