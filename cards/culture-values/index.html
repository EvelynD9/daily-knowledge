Values and norms play different roles

Values express what a group considers important; norms guide behaviour.

The idea

A broad value can be supported by several specific expectations. Stated values and actual behaviour can differ.

An example

Respect is a value; waiting your turn in a queue is a norm that may express it.

Put it into practice

Separate the principle from the expected action.
