The wing's angle is relative to the airflow

Angle of attack is the angle between the wing chord and relative airflow.

The idea

It is different from the aircraft's pitch attitude relative to the horizon. A changing flight path changes the relationship.

An example

The same nose attitude can correspond to different angles of attack during different flight paths.

Put it into practice

Name the reference line before comparing angles.
