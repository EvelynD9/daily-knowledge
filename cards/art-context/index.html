Context can change an object into art

Meaning depends not only on what an object is, but on where, when, and why it is presented.

The idea

A familiar object placed in a gallery can shift attention from craftsmanship to choice, authorship, institutions, and the definition of art itself.

An example

The same chair is furniture in a kitchen, evidence in a courtroom, and a cultural statement in a museum installation.

Put it into practice

Ask what changed when an ordinary object entered an artistic setting: the object, or the way you were invited to see it?
