Build a mind you’re proud of.

Memory is evidence with a perspective

Oral history records people's recollections and interpretations of the past.

The idea

Interviews preserve experiences that documents may omit. Memory and later context can reshape an account, so comparison remains important.

An example

A worker's interview adds daily experience to a factory's official records.

Put it into practice

Value the testimony while checking dates and other evidence.
