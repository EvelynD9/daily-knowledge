Build a mind you’re proud of.

Start with the customer's problem

A value proposition explains a useful benefit for a particular customer.

The idea

Features describe a product; value explains why someone would choose it. Testing the problem comes before assuming demand.

An example

A booking tool matters to a busy customer because it reduces coordination, not merely because it has many buttons.

Put it into practice

Ask whom it helps and which difficulty it removes.
