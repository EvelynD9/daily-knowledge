History makes changes easier to manage

Version control records changes so earlier states can be compared or recovered.

The idea

A useful history explains what changed and supports collaboration. It is more structured than a folder of files named final-final.

An example

A team can identify which edit introduced a problem and inspect the previous working version.

Put it into practice

Record meaningful changes with clear explanations.
