A wide road can still have a long journey

Bandwidth describes capacity; latency describes delay.

The idea

More capacity can move more data at once, but it does not automatically reduce the time for a request to travel and return.

An example

A video call can feel delayed despite a connection advertised with a high download rate.

Put it into practice

Ask about response time as well as transfer capacity.
